## 三网优化VPS，优化的到底是什么？

三网指电信、联通、移动三家运营商；优化指的是大陆访客和服务器之间的流量走这三家各自的精品线路，而不是普通骨干网。对应关系大致是：电信看CN2 GIA，联通看9929（商家标签比较乱，CU2、CUII、CUG都常见），移动看CMIN2（不少商家直接写CMI）。

精品线和普通线路的差距，主要体现在晚高峰。电信163骨干（AS4134）、联通AS4837这类常规线路，在晚上八点到十一点经常拥堵，速度波动明显；CN2 GIA、9929、CMIN2是各家拿出来的精品通道，优先级更高，高峰期的延迟和丢包都稳得多。另外电信CN2还分GIA和GT两档，一般GIA的全程覆盖和优先级更好，看到只写“CN2”的宣传时值得多问一句。

还有一点容易被忽略：去程和回程是两条路。去程是你把请求发到服务器，回程是服务器把页面、视频、文件推回给你。对建站、流媒体这类场景，回程承载了大头流量，回程质量直接决定下载速度；反过来，如果主要是往服务器上传备份和素材，去程就更重要。市面上很多机型只优化回程——比如Evoxt马来西亚那款，电信CN2 GIA和联通9929都是明确写在回程上的。所以看到“直连”“优化”这类词，先确认它说的是哪个方向、哪条线。

不等。直连说的是路由不绕路，走电信163（AS4134）、联通AS4837也能直连，但它们属于普通骨干，晚高峰的表现和精品线不在一个水平。判断方法很简单：看商家有没有写具体线路名（CN2 GIA、9929、CMIN2），或者直接查AS号。
